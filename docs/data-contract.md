## Query options

Standard DAB REST options work on every endpoint: `$select`, `$filter`, `$orderby`, `$first`, `$after`.
Example: `GET /api/vw_activity?$orderby=event_id desc&$first=15`.

## Conventions

- Amounts are AED (`*_aed`); the console divides by 1e6 for AED m.
- Percentages are 0-100 with one decimal (`*_pct`).
- Timestamps are UTC `datetime2` serialised without a zone suffix.
- A column change is a contract change: update the view, the DAB config, the emulator and run
  `python3 tools/check_contract.py`.
