Data API builder (DAB) — end-to-end technical flow

Enterprise view of the live-read path: source event → Fabric ingest → governed core (contract views + row-level security) → Data API builder → API Management → the portal. Press Simulate source input — or watch the loop — and follow one change from the ground to the glass.

What DAB is: Microsoft Data API builder — an open-source, generally available engine that auto-generates secure REST and GraphQL endpoints directly from database views and stored procedures. One JSON configuration file, zero custom API code, free with no premium tier, deployed as a stateless container inside our own tenant. It replaces the custom middleware we would otherwise have to build for live reads.

Client Intelligence Portal — Source-to-Target Data Mapping
Scenario 1 · our data, our systems · serving pattern: contract views → Data API builder (DAB) → APIM → portal
Purpose
One document holding every portal field (target) against the system field that feeds it (source), with transformation, cadence, ownership and status — the working annex to the JSON data-contract spec.
How to use
Filter the Mapping tab by portal panel or source system. In the working Excel (cip-data-mapping-simulated.xlsx), complete or correct the blue columns; Status and Shape drive the colour coding. Gaps & TBC counts anything not fully mapped.
Conventions
Target = what the portal shows (panel · JSON key in the contract view). Source = system of record (system · entity · field). In the Excel, blue text = input to complete/confirm · black = fixed structure.
Status values
Mapped source confirmed and reachable  ·  Partial source known, transformation or access unresolved  ·  Gap no digital source exists today  ·  TBC awaiting SME confirmation.
Scenario note
All rows are Scenario 1. Scenario 2 (hybrid) mappings are excluded by design; they follow after client IT/OT confirmation per site.
Open items — counted live from the Mapping tab. Action rule: every Partial / TBC / Gap row must carry an owner and a note; Gaps feed the Fabric backlog, TBCs feed the SME forms.
